🎮 MiniGames

MiniGames is a browser-based collection of interactive mini-games built as a framework-free frontend application.

The project demonstrates the ability to create a complete, responsive, and interactive user interface using only TypeScript, HTML, and SCSS, without relying on frontend frameworks or ready-made UI component libraries.

✨ Features
🎮 Collection of interactive mini-games
🖥️ Full custom UI built from scratch
📱 Responsive design for different screen sizes
⚡ Interactive gameplay powered by TypeScript
🎨 Custom styling with SCSS
🧩 Reusable UI components and styles
🔄 Game restart and reset functionality
🏆 Score tracking
🚫 No frontend frameworks
🚫 No ready-made UI component libraries

🛠️ Technologies

The project is intentionally limited to:

HTML5 — page structure and semantic markup
TypeScript — application logic, game mechanics, and DOM interactions
SCSS — styling, layouts, animations, and responsive design
Not Used

This project does not use:

React
Vue
Angular
Next.js
Tailwind CSS
Bootstrap
Material UI
Other ready-made UI component libraries
